  Python snippet to reproduce Fig 4A loss curve (model 0):
  ```
  import pickle, pathlib
  import matplotlib
  matplotlib.use('Agg')
  import matplotlib.pyplot as plt

  base = pathlib.Path('retrocueing_RNN/rerun_outputs/experiment_1/sigma0.07/kappa5.0/nrec200/lr0.0001')
  train_file = base/'training_data'/'training_data_model0.pckl'
  with open(train_file, 'rb') as f:
      track = pickle.load(f)
  loss_np = track['loss_epoch'].cpu().numpy()
  epochs = range(1, len(loss_np)+1)
  plt.figure(figsize=(6,4))
  plt.plot(list(epochs), loss_np, 'k-')
  plt.xlabel('Epoch'); plt.ylabel('Loss'); plt.title('Training loss (model 0)')
  plt.tight_layout()
  figdir = base/'figs'; figdir.mkdir(exist_ok=True, parents=True)
  plt.savefig(figdir/'fig4A_loss_model0.png', dpi=300)
  plt.savefig(figdir/'fig4A_loss_model0.svg')
  ```
